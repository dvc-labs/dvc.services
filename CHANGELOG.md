# Changelog

## 0.1.0 — 2026-10-23

Initial dvc.services release for the dvc.labs Discord server.

- Added a persistent welcome/verification embed with a Verify button and ordinary member-role assignment.
- Added private outcomes, repeated-click protection, membership-screening checks, and role/permission validation.
- Added `/about` and a Manage Server-only `/verification` panel command, registered automatically in the configured guild.
- Added branded Discord activity logs and structured console logs for commands, verification, startup, panel changes, reconnection, and graceful stops.
- Added Node.js 24/TypeScript source, a production Dockerfile, optional hardened Compose configuration, and liveness/readiness endpoints.
- Added automated tests, GitHub CI, Dependabot, safe environment examples, security/contribution policies, and Discord/loon.host setup guides.
